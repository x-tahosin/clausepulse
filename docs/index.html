CONSENT-FIRST BIOMETRIC INSTRUMENT ON-DEVICE PROCESSING

Camera Consent & SmartSpectra Data Boundaries

ClausePulse uses the Presage SmartSpectra SDK (`@smartspectra/node-sdk@3.5.0`) and local optical frame analysis to detect unverified skimming and reading apnea on contracts, production runbooks, and local Git diffs.

01 / 100% Local On-Device Frame Processing

Webcam frames are processed locally on your machine to compute respiratory chest traces (`upperTrace`), pulse plethysmography, HRV, and facial landmarks. No raw video, images, or audio are ever uploaded.

02 / Dual-Engine Architecture (SDK + Local Optical)

With a Presage API key, ClausePulse runs the native C++ `SmartSpectraSDK` pipeline. Without a key, clicking Start Live Camera immediately opens your webcam in Local Optical Mode so you can test live with zero setup barriers.

03 / Strict Non-Medical Scope & Personal Baseline

All physiological readings are relative within-session interaction estimates compared against your own stationary calibration. ClausePulse does not diagnose, treat, or evaluate any medical condition.

04 / Instant Revocation & Cryptographic Receipts

Stop the camera, blur the preview, or wipe all local receipts and OS-encrypted keys (`safeStorage`) with one click. Exported Read Receipts contain only aggregated clause telemetry and a real RFC 6234 SHA-256 digest.
